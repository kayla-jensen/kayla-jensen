# Publish your GitHub profile

1. Sign in to GitHub and create a **public repository with exactly the same name as your GitHub username**.
2. Select **Add a README file** when creating the repository, or add it afterward.
3. Replace the repository's `README.md` with the one in this folder.
4. Upload the entire `assets/` folder to the same repository, preserving its name and file structure.
5. Commit your changes. GitHub displays the profile README on your public profile automatically.

## Customize before publishing

- The supplied resume names **Kayla Jensen**. Update the displayed name and links if this profile should represent someone else.
- The **email address** is visible to the public in this profile. Delete the email buttons and email link if you prefer not to disclose a personal email address.
- The resume does not provide a GitHub username or any project repositories. Add your actual projects and pinned repositories once available. Avoid using invented project links or performance metrics.
- `assets/*.svg` are all local assets in this package; they can be modified without external design software. The social badges use Shields.io and require internet access.
